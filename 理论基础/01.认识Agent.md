# 认识Agent

### LLM（大语言模型）

简单来说，可以看作是通过大量数据训练出来的一种概率机制，给定一串自然语言的输入，之后便开始通过概率猜测下一个输入；

但是只能通过训练过的数据得出结论。

直接问大模型：

```
你：今天天气怎么样？
LLM：抱歉，无法获取实时数据。
```

### Agent（智能体）

LLM（大脑）只会思考（通过之前的数据训练），但无法动手（使用工具），所以在问他天气的时候就无法获取到实时的天气，并且 LLM 还很健忘，不会将你以前说过的话记住；

而智能体就相当于给 LLM 加上了手（工具）、记忆、规划，使得它能够完成一次完整的对话：

```
你：今天天气怎么样
  Agent内部：
    1、Think（思考）：用户要知道天气 -> 需要调用天气 API
    2、Act（行动）：调用 get_weather('') -> 发送 HTTP 请求获取天气
    3、Observe（观察）：返回 {"明天": "晴，25°C"} -> 拿到真实数据
    4、用自然语言组织结果给你
Agent：北京今天天气晴朗，气温25°C
```

它的工作流程如下：

```
---> Perceive（感知）：接受用户输入和上一次的行动结果
|    Think（思考）：LLM 分析当前状态，决定下一步
|    Act（行动）：调用工具或生成最终答案
---  Observe（观察）：获取行动结果

此循环被称为「ReAct 循环」(Reasoning + Acting)
```

所以，LLM 是大脑，而 Agent 则是给大脑装上手，让它能查，能算，能操作。
