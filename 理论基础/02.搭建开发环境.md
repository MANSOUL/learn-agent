# 搭建开发环境

### 安装 python

进入 https://www.python.org/downloads/macos/ 下载 3.10+ 版本安装；

完成后查看是否安装成功：

```shell
python3 --version
pip3 --version
```

### 配置环境变量

```shell
# 编辑shell配置文件（根据您的shell类型）
vim ~/.zshrc

# 配置别名
alias python=python3
alias pip=pip3

# 使配置生效
source ~/.zshrc
```

### 安装所需要的依赖

以当前 python 解释器调用 pip，从 requirements.txt 中逐行读取报名和版本。

```shell
python -m pip install -r requirements.txt
```
